# One Question at a Time

Depth comes from narrowing. A [[Query]] gathers the material around one board question, so the analysis stays focused, reviewable and small enough to argue with.

A Query starts with a name and a focus, with AI offering focuses to start from. The Query Focus Modal lets the director rewrite the focus as the evidence changes what they want to know. The [[Board Simulation Room]] tests one Query's scenario, not everything at once. The broad view stays in the [[Governance Brain]].

This rules out one sprawling analysis of the whole Vault, and scenarios run against evidence that was never gathered for them.
