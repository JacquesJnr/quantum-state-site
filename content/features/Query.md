# Query

**Built on:** [[Human Authority]], [[See the Evidence]], [[Traceable to Quanta]], [[A Candid Assistant]], [[Show What Isn't Known]], [[The Director Decides]], [[One Question at a Time]], [[Findings Outlive the Meeting]]

A Query gathers what matters around one board question. Insights that Morgan judges worth keeping, from anywhere in the [[Governance Brain]], come together here instead of staying scattered across nodes. Narrowing to one question at this stage is what keeps the next stage, the [[Board Simulation Room]], from testing everything at once.

![[x/Images/App Maps/Mo-28-Sep QS App Map 2.0 S5 Gather.png|App map stage 5, Gather around a question. Create new Query (name, focus, AI-suggested focuses) leads to the Query workspace: header, overview, Analysis (strategies, consequences, assumptions, risks and open questions), Query graph, readiness and AI chat. From there the director adds or removes insights through the Insight Chooser, edits the focus, generates the Analysis, or opens the Board Simulation Room]]

## What it does for Morgan

Starting an insight from [[Insight Cards]] opens [Create new Query](https://www.figma.com/board/WITVErwq2RH0fhCbBqVAJs?node-id=13-4309), where Morgan names it and sets its focus, with AI offering three to five suggested focuses drawn from the insights carried in. Confirming opens the [Query](https://www.figma.com/board/WITVErwq2RH0fhCbBqVAJs?node-id=13-4310) surface itself: the name and focus, a summary of what's new, the Query's own graph showing only its insights and how they relate, a readiness indicator for the risk framework and financial data, and the Analysis — AI-written strategies, consequences, assumptions, risks and open questions, generated from the insights Morgan has gathered.

Morgan adds insights through the [Insight Chooser](https://www.figma.com/board/WITVErwq2RH0fhCbBqVAJs?node-id=13-4311), which searches the vault and can surface AI-suggested related insights while a toggle is on. He edits the focus through the [Query Focus Modal](https://www.figma.com/board/WITVErwq2RH0fhCbBqVAJs?node-id=13-4312) as the evidence changes what he wants to know. Adding or removing an insight reworks the Analysis around the new evidence. From here he opens the Board Simulation Room to test what could change.

## Conditions to use it

- At least one insight, carried in from an Insight Card, is needed to create a Query.
- The Analysis has to be generated before the Board Simulation Room is meaningful to open, even though the room itself doesn't yet enforce that.
- Readiness for financial data depends on how the source setup answered the willingness question in [[Governance Vault]] — historical records only, or a live connection.

## Still open

- Whether a Query is a temporary working set or something kept and returned to, and who owns it, isn't settled.
- Ideas for the Query graph include AI-suggested insights shown as greyed, unaccepted nodes; the current Query surface doesn't draw that state.
- An Analysis going stale when an insight is added or removed, and any way to see an earlier version of it, isn't specified.
