# Query

**Built on:** [[Human Authority]], [[See the Evidence]], [[Traceable to Quanta]], [[A Candid Assistant]], [[Show What Isn't Known]], [[The Director Decides]], [[One Question at a Time]], [[Findings Outlive the Meeting]]

A Query gathers what matters around one board question. Nodes from anywhere in the [[Governance Brain]], and the relationships between them, come together here instead of staying scattered across the graph. Each node brings its whole document, and the insights about it come along as notes on that node. Narrowing to one question at this stage is what keeps the next stage, the [[Board Simulation Room]], from testing everything at once.

## What it does for Morgan

A Query can start from a selection in the Graph, from "Add to a Query" in a node's or a relationship's details, from "Create a query" on a [[Smart Search]] answer, from [[Insight Cards]], or from scratch. Each route opens [Create new Query](https://www.figma.com/board/WITVErwq2RH0fhCbBqVAJs?node-id=13-4309), where Morgan names it and sets its focus, with AI offering three to five suggested focuses drawn from the nodes carried in. Confirming opens the [Query](https://www.figma.com/board/WITVErwq2RH0fhCbBqVAJs?node-id=13-4310) surface itself: the name and focus, a summary of what's new, the Query's own graph showing only its nodes and how they relate, a readiness indicator for the risk framework and financial data, and the Analysis — AI-written strategies, consequences, assumptions, risks and open questions, generated from what Morgan has gathered.

Morgan adds nodes and relationships through the [Node Chooser](https://www.figma.com/board/WITVErwq2RH0fhCbBqVAJs?node-id=13-4311), a small graph that works like the main Graph. It searches the vault and can surface AI-suggested related nodes while a toggle is on. He edits the focus through the [Query Focus Modal](https://www.figma.com/board/WITVErwq2RH0fhCbBqVAJs?node-id=13-4312) as the evidence changes what he wants to know. Adding or removing a node or a relationship reworks the Analysis around the new evidence. From here he opens the Board Simulation Room to test what could change.

## Conditions to use it

- A Query can start empty, or from one or more nodes or relationships. A node brings its whole document.
- The Analysis has to be generated before the Board Simulation Room is meaningful to open, even though the room itself doesn't yet enforce that.
- Readiness for financial data depends on how the source setup answered the willingness question in [[Governance Vault]] — historical records only, or a live connection.

## Still open

- Whether a Query is a temporary working set or something kept and returned to, and who owns it, isn't settled.
- Ideas for the Query graph include AI-suggested nodes shown as greyed, unaccepted nodes; the current Query surface doesn't draw that state.
- An Analysis going stale when a node or relationship is added or removed, and any way to see an earlier version of it, isn't specified.
- How a relationship between nodes shows its own details in the [[Node Details Panel]] isn't specified.
